# مملكة الأشقر — برنامج مراسلات فوري (Node.js)

## طريقة التشغيل (ويندوز)
1. ثبّت Node.js من https://nodejs.org (اختر نسخة LTS) إذا ما كان مثبت عندك.
2. فك ضغط المجلد كامل في أي مكان بجهازك.
3. اضغط يمين على ملف `start.ps1` واختر **Run with PowerShell**.
   - أول مرة رح يثبت المكتبات المطلوبة تلقائياً (يحتاج نت).
   - بعدها بيفتح المتصفح تلقائياً على `http://localhost:3000`.
4. سوّي حساب (تسجيل)، وشارك رابط الجهاز مع أصدقائك حسب الشرح تحت.

> إذا واجهتك رسالة أن التنفيذ ممنوع (execution policy)، افتح PowerShell كـ Administrator ونفذ مرة وحدة:
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

## طريقة التشغيل (بدون PowerShell)
```
npm install
npm start
```
ثم افتح `http://localhost:3000` بالمتصفح.

## هل البرنامج يشتغل من الإنترنت فعلاً؟
البرنامج سيرفر حقيقي يشتغل بالـ Node.js، وأي جهاز على نفس الشبكة يقدر يدخله عن طريق الـ IP الخاص بجهازك (مثلاً `http://192.168.x.x:3000`).
لجعله متاح لأي شخص من أي مكان بالعالم (استضافة حقيقية على الإنترنت) عندك خياران:
- **بورت فورواردنغ (Port Forwarding)** على الراوتر لجهازك، مع استخدام IP ثابت أو خدمة مثل Ngrok / Cloudflare Tunnel لتجربة سريعة.
- **استضافة على سيرفر سحابي** (مثل Render أو Railway أو VPS) — ترفع نفس هذا الكود وتشغّله هناك بدل جهازك، وساعتها يكون متاح 24 ساعة لأي شخص برابط ثابت.
جهازك الشخصي عادةً لازم يكون شغّال ومتصل بالنت طول الوقت حتى يقدر أصدقاءك يدخلون، وهذا سبب ليش أغلب برامج المراسلات تستضيف على سيرفرات سحابية دائمة التشغيل بدل جهاز شخصي.

## الميزات المتوفرة
- تسجيل حساب + دخول، وكل حساب ياخذ **آيدي فريد (7 أرقام)** تلقائياً.
- زر إظهار/إخفاء كلمة المرور (👁) بشاشة الدخول وإنشاء الحساب.
- البحث عن أي شخص بالآيدي (يظهر اسمه وصورته).
- نظام طلبات صداقة حقيقي: ترسل طلب، والطرف الثاني يشوفه بتبويب "الأصدقاء" ويقدر يقبله أو يرفضه — يكفي طرف وحد يرسل والثاني يقبل حتى تصير الصداقة.
- تقدر تراسل أي شخص بالآيدي مباشرة حتى قبل ما تصيرون أصدقاء، وتوصله الرسالة فوراً بقائمة محادثاته حتى لو أول مرة.
- محادثات فردية، ومحادثات جماعية (تختار الأعضاء وتسمي الكروب).
- إرسال رسائل نصية فورية (Real-time عبر Socket.io)، مع ظهور صورة المرسل (الأفتار) بجانب كل رسالة.
- إرسال صور وفيديوهات داخل المحادثة.
- ملف شخصي: تغيير الاسم والصورة الشخصية (أفتار).
- إعدادات المحادثة (أيقونة الترس ⚙ أعلى المحادثة الفردية):
  - كتم / فتح إشعارات الشخص.
  - تغيير خلفية المحادثة من ألبوم الصور — وتظهر نفس الخلفية للطرفين في نفس المحادثة فوراً.

## هيكل الملفات
```
server.js        السيرفر الرئيسي (Express + Socket.io)
db.js            تخزين البيانات بملف JSON بسيط (data/db.json)
public/          واجهة المستخدم (HTML/CSS/JS)
uploads/         الصور والفيديوهات والأفتارات المرفوعة
start.ps1        سكربت تشغيل تلقائي لويندوز (PowerShell)
```

## ملاحظة أمان
هذا مشروع أساسي جاهز للتجربة والتطوير. قبل ما تنشره لعدد كبير من الناس على الإنترنت،
يفضّل تغيير `secret` بملف `server.js` إلى قيمة عشوائية سرية، وإضافة HTTPS عبر خدمة الاستضافة.
